VERSION 1.12.3 16 AUG 2026

Easier installs and updates

  • Installed builds can check a configured public GitHub Releases page for newer versions.
  • The game asks before downloading an update and again before restarting.
  • Update errors are logged without interrupting a run.

Smarter unattended runs

  • Move decisions use live damage forecasts and opponent threat analysis.
  • Level-up moves can replace weaker attacks instead of being rejected.
  • Lures are avoided and critical team health no longer disables AFK mode.

One install, easy upgrades

How updates work

  1. 1

    Install once

    Download the latest NSIS installer and install over an older Keagan Edition copy.

  2. 2

    Get notified

    The installed game checks the public release feed and asks before downloading anything.

  3. 3

    Keep your progress

    Restart to finish the update while retaining the same login, saves, settings, and AFK data.
